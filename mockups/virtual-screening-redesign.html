DESIGN NOTES

  • Option A — Pill badge on the poster says "SCREENING" (same position/style as Netflix, Hulu, etc.). Festival name fills the gold bar at the bottom. Clean, consistent with existing badge patterns. If a movie also has a streaming badge, the screening pill would replace it (screening movies are on Eventive, not streaming services).
  • Option B — Full-width banner across the bottom of the poster says "★ VIRTUAL SCREENING ★" (more prominent, eye-catching). Festival name underneath in an outlined bar (lighter, lets the gold border do the heavy lifting). More visual emphasis on the screening status.
  • Both options solve the problem: you see the festival name at a glance on the card — no need to open the lightbox.
  • Long festival names are handled with smaller font size and abbreviations per style guide ("Intl." for International, "Film Fest" for Film Festival).
  • The gold border + glow stays the same on both — it already signals "this is a screening."
