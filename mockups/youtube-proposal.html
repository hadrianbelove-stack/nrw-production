YouTube Discovery Proposal

Finding new feature films on YouTube daily (paid and free)

Options at a Glance

A. YouTube Data API v3 ★★★★★
Cost: Free (10K quota/day)
Effort: Medium

Official Google API. Search by keywords, filter by duration (>20 min), category, and date.

  • Most reliable - won't break
  • Generous daily quota
  • Structured data
  • Can't detect paid vs free
  • No exact runtime filter
B. Curated Channel RSS ★★★★☆
Cost: Free
Effort: Low

Monitor specific YouTube channels via RSS feeds. No authentication needed.

  • Zero API cost
  • Simple to implement
  • Only last 10 uploads
  • Must curate channel list
C. Playwright Scraping ★★☆☆☆
Cost: Free
Effort: High

Current method. Automates browser to scrape YouTube search results.

  • Can detect paid vs free
  • Sees what users see
  • Brittle - breaks often
  • Account suspension risk
  • Found 0 films last run
D. Third-Party APIs ★★★★☆
Cost: $50-200/month
Effort: Low

SerpApi, Apify, Zyla Hub. Managed scraping services.

  • Enterprise-grade
  • Handles anti-bot
  • Monthly cost
  • Overkill for indie films
E. Hybrid Approach RECOMMENDED
Cost: Free
Effort: Medium
Reliability: ★★★★★

Combine API + RSS + TMDB for best coverage. If one method fails, others continue.

Recommended: Hybrid Pipeline

DAILY PIPELINE
1. RSS FEEDS (Zero cost)
→ Monitor 10-20 curated channels
→ Get new uploads instantly
2. YOUTUBE DATA API (Weekly)
→ Search: "indie film", "full movie free", etc.
→ Filter: duration >70 min, published this week
→ Cost: ~200 quota units per run
3. TMDB CROSS-REFERENCE
→ Match YouTube finds to TMDB entries
→ Get metadata: director, genres, ratings
→ Validate it's a real film (not compilation)
4. PLAYWRIGHT (Monthly, optional)
→ Only for price detection when needed
→ Reduces account suspension risk

Implementation Phases
