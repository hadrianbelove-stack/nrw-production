# NRW iOS App Assets

## Required Assets

Before submitting to App Store, add these files:

### App Icon
- `icon.png` - 1024x1024 app icon (required for App Store)

### Launch Screen
- `splash.png` - Launch screen image

### Service Logos (optional)
Place in `logos/` subdirectory:
- `amazon.png` - Amazon Prime Video logo
- `apple_tv.png` - Apple TV logo
- `netflix.png` - Netflix logo
- Other streaming service logos as needed

## Asset Guidelines

- Use NRW brand colors:
  - Primary teal: #00d4aa
  - Dark background: #0a0a0a
- App icon should be on dark background with teal accent
- All logos should be square, minimum 128x128 pixels
